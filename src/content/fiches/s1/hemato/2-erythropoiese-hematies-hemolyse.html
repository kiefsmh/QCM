1. Érythropoïèse : de la CSH à l’hématie

Érythropoïèse : production des globules rouges / hématies.
CSH → Progéniteurs BFU-E puis CFU-E → Précurseurs = érythroblastes → Réticulocytes → Hématies matures
  • Les progéniteurs restent non identifiables morphologiquement.
  • Les précurseurs sont identifiables et engagés dans une seule lignée.
  • BFU-E = premier progéniteur spécifique érythrocytaire dans le support.

2. Maturation érythroïde

  • 1 précurseur → 16 réticulocytes.
  • Au stade d’érythroblaste acidophile, le noyau / ADN est expulsé.
  • Le réticulocyte ne se divise plus mais garde encore de l’ARN.
  • Perte de l’ARN → hématie mature.
  • Différenciation : cellules de plus en plus petites, moins basophiles et plus acidophiles.
Piège QCM : le réticulocyte n’a plus d’ADN mais possède encore de l’ARN.

Myélogramme

  • Ponction liquide de moelle + coloration + comptage.
  • 15–25 % d’érythroblastes dans la moelle selon le texte.
  • Érythroblastes absents du sang normal.

3. Réticulocytes : régénératif ou arégénératif ?

Dosage par automate fluorescent ou Bleu de Crésyl.

> 120 G/L

Anémie régénérative → cause périphérique, compensation médullaire.

< 120 G/L

Anémie arégénérative → cause centrale, pas de compensation.

Exemple : 8 % de réticulocytes × 4,2 T/L d’hématies = 0,336 T/L = 336 G/L.

5. EPO & facteurs nécessaires

  • Androgènes → progéniteurs.
  • SCF → cellules souches.
  • EPO → uniquement lignée érythrocytaire.
  • Fer + B6 → synthèse Hb.
  • B9 + B12 → synthèse ADN.
  • Facteurs inhibiteurs : IFN-γ, TNF-α, TGF-β.

EPO

  • Produite par cellules péritubulaires du rein en hypoxie.
  • Altérable par cytokines inflammatoires et cisplatine.
  • Action des BFU-E tardives aux érythroblastes basophiles.
  • Hb ↓ → EPO ↑ ; Hb ↑ → EPO ↓.
  • Récepteur associé à JAK2.

7. Absorption du fer & hepcidine

Fer héminique

Fe²⁺, surtout animal, mieux absorbé.

Fer non héminique

Fe³⁺, plutôt végétal, plusieurs étapes avant absorption.

  • Absorption surtout duodénale, petite partie jéjunale.
  • Le support présente DMT1 comme intervenant dans la réduction/absorption de Fe³⁺.
  • Ferroportine : sortie du fer entérocytaire et macrophagique.
  • Hepcidine hépatique : bloque/dégrade la ferroportine → baisse absorption et libération du fer stocké.

Inhibiteurs

  • Argile, pansements digestifs, thé (tannates/phytates), tétracyclines, phosphoprotéines du jaune d’œuf.
Pertes : ≈ 1 mg/24 h.
Perls : coloration du fer, décrit comme verdâtre dans le support.

Anémies microcytaires citées

  • Carence martiale +++.
  • Inflammation chronique avec hepcidine ↑.
  • Thalassémie.

9. Mégaloblastose

Carence B9/B12 → défaut synthèse ADN → maturation nucléaire bloquée → asynchronisme nucléo-cytoplasmique → macrocytose / mégaloblastose
  • Impact sur plusieurs lignées.
  • Hypersegmentation des PNN.
Piège : déficit B9/B12 → anémie macrocytaire, pas microcytaire.

11. Membrane du GR

  • Bicouche lipidique + protéines + structures antigéniques.
  • Protéines citées : spectrine, bande 3, ankyrine, protéine 4.1.
  • Rôle essentiel : élasticité et déformabilité.
  • Sphérocytose : défaut membranaire → GR sphérique → destruction prématurée.

12. Hémoglobine

Constituée de globine + hème contenant le fer.

HbChaînesÀ retenir
Hb Aα₂β₂Majoritaire adulte sain, >80 %
Hb Fα₂γ₂Fœtale, plus affine pour O₂
Hb A2α₂δ₂3–5 %
Après naissance : β augmente et remplace progressivement γ.

Pathologies de synthèse

  • Thalassémie : déficit d’une chaîne de globine → anémie microcytaire.
  • Drépanocytose : mutation des gènes des chaînes de globine.
  • ALA synthétase + B6 : iatrogénie possible (isoniazide, D-pénicillamine).
  • Porphyries : déficit enzymatique de synthèse de l’hème.
  • Saturnisme : plomb bloque utilisation du fer → tableau mimant carence martiale.

13. Métabolisme du globule rouge

Pas de mitochondries. Le GR dépend de la glycolyse.
ProduitRôle
ATPPompes ioniques, équilibre hydrique, intégrité membranaire.
NADH / NADPHProtection anti-oxydante.
2,3-DPGRégule l’affinité de l’Hb pour O₂ et sa libération tissulaire.
  • Pyruvate kinase : déficit → ATP ↓ → fragilité / hémolyse.
  • G6PD : déficit → défense anti-oxydante ↓ → hémolyse lors de stress oxydatif.

14. Hémolyse physiologique

Destruction normale des GR à environ 120 jours.

≈85 %

Hémolyse tissulaire : surtout rate + foie, moindrement moelle.

≈15 %

Hémolyse intravasculaire.

Hb → Globine → acides aminés Hb → Hème → Fer (recyclé via transferrine / ferritine) + Protoporphyrine → bilirubine → élimination

En intravasculaire, l’Hb libre est captée par haptoglobine.

15. Hémolyse pathologique

Destruction avant 120 jours.

Clinique

  • Fatigue, pâleur, dyspnée, hypoxie.
  • Ictère.
  • Splénomégalie.
Triade illustrée : ictère + pâleur + splénomégalie.

17. Démarche diagnostique devant une anémie

ANÉMIE ↓ VGM : micro / normo / macro ↓ CCMH / TCMH ↓ Réticulocytes : >120 G/L régénérative ; <120 G/L arégénérative ↓ Si installation brutale + ictère → bilan de lyse ↓ Bilirubine ↑ + LDH ↑ + haptoglobine ↓ ↓ Cause corpusculaire ou extra-corpusculaire ?
Réflexe du cours : anémie hémolytique généralement normocytaire et régénérative.

18. Pièges et incohérences du support

1. Érythroblastes médullaires : texte = 15–25 %, correction QRM = 15–20 %.
2. DMT1 : présenté comme une « enzyme » de réduction de Fe³⁺ dans le support ; formulation conservée telle quelle.
3. B9 explorations : unités incomplètes dans le tableau (« 5–15 ng », « 160–640 ng/m ») ; non complétées artificiellement.
4. Hématies cibles / anneau de Cabot : le texte mélange ces termes alors que les images les distinguent ; la fiche les sépare.
5. Porphyrie : texte = déficit enzymatique de synthèse de l’hème ; correction QRM = « touche la globine ». Contradiction interne.
6. Spectrine : le cours la place dans l’architecture membranaire mais le corrigé rejette l’expression « protéine de surface » car elle est intracellulaire.
7. Seuils bilan de lyse : reproduits exactement de l’encadré du support, sans substitution.
